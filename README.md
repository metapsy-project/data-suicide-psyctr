## **The `data-suicide-psyctr` dataset** 📊 


The `data-suicide-psyctr` dataset is a meta-analytic research domain [MARD](https://docs.metapsy.org/uploads/ebmental-2022-300509.pdf)) comprising studies on the effect of psychotherapy on suicidal ideation and suicide attempts. This MARD is part of the  [Metapsy project](https://www.metapsy.org/). This dataset includes psychotherapy vs. control ('psy vs ctr') comparisons. Effect sizes are provided for outcomes at post-test. Suicidal ideation and suicide attempts are different outcomes and are analysed separately.

The dataset follows the Metapsy data standard. All included information has been independently extracted two researchers. Risk of bias ratings were conducted using the Cochrane Collaboration Risk of Bias Tool (Version 2).

The dataset follows the [Metapsy data standard](https://docs.metapsy.org/data-preparation/format/).
